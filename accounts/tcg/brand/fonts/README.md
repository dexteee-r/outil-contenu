# Polices de marque

Fichiers `.ttf` / `.otf` utilisés par les miniatures (étiquette, « ? » du teaser). La police est
choisie dans `account.yaml` → `brand.fonts.title` (ex. `brand/fonts/Montserrat-Black.ttf`).

Les fichiers ne sont pas versionnés : certaines licences interdisent la redistribution (Burbank
Big Condensed est une police commerciale). Montserrat, Anton et Poppins sont sous licence OFL.

Aperçu de toutes les polices du dossier : `pnpm -C spikes fonts tcg`.
