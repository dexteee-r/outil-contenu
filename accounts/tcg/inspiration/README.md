# Inspiration — miniatures

Miniatures de référence pour le style du compte. Ces images appartiennent à leurs créateurs :
elles restent sur ce PC (ignorées par git) et servent seulement à analyser la mise en page.

- Ajouter des vidéos YouTube / Shorts : `pnpm inspiration <lien> [<lien>…]` ou `pnpm inspiration --file liens.txt`
- Ajouter d autres images (TikTok, Instagram…) : les déposer ici à la main, en PNG ou JPG.
- `index.json` garde le titre, la chaîne et le lien de chaque miniature récupérée.
